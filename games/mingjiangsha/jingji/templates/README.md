# 竞技场脚本 —— 要重新裁切的模板

**这个目录里的 PNG 是我从 `rawMaterial/` 自动裁的，坐标有偏移，请按下面的清单重裁。**
文件名的**位置（y 坐标）**必须保留：代码用 `region` 限定搜索范围，和模板位置有关。

## 裁切要求

| 项 | 要求 |
|---|---|
| 源图 | 就用你丢在 `rawMaterial/` 的那 15 张（2560×1392） |
| 基准 | **各图左上角**（截图左上 = 客户区左上，两者一致） |
| 内容 | 只裁**元素本体**（文字 / 按钮 / 图标），**别带背景** —— 背景一直在动（花瓣、光效、飘雪），带上会拉低分数 |
| 尺寸 | 宽高各留 2~4px 边距即可，别太大；小一点匹配更快也更准 |
| 格式 | PNG，文件名严格按下面来 |

## 提示弹窗不用模板

`tip1.png` / `tip2.png` 那两步（勾选「本次登录不再提示」+ 点「确定」）**用固定坐标**：

* 位置固定、没有别的同类元素，找图的收益不如"少维护两张图"；
* 坐标在 `pages.py` 的 `TIP_CHECKBOX` / `TIP_CONFIRM`。

（`tip1.png` 里复选框是**空的**、`tip2.png` 里是**打了勾的** —— 这正是"勾选前/勾选后"。）

## 重裁之后怎么确认对不对

```bash
uv run python -m games check mingjiangsha/jingji     # 先看定义有没有错
uv run python -m games run mingjiangsha/jingji --dry-run --max-ticks 3
```

干跑会**真的抓屏、真的识别**（只是不下发点击）。界面上的「识图日志」会显示
每次匹配的**带框图 + 分数**，一眼能看出哪张模板对不上、分数差多少。
